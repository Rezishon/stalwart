# Single-Binary Zero-Dep Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline; user already said go) or superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One executable (plus OS-specific twins) that contains admin WebUI and DeltaChat relay, starts with zero network and zero disk writes for frontends.

**Architecture:** Compile-time embed. `build.rs` walks committed asset trees and emits `include_bytes!` maps. Runtime GitHub fetch + unzip-to-temp for the default WebUI is removed. Version string is `0.16.25-rlN` (Cargo semver stays `0.16.25`). CI ships musl linux (amd64/arm64/armv7), Windows x64, FreeBSD x64, and a scratch multi-arch Docker image.

**Tech Stack:** existing `zip` crate as a build-dep, `include_bytes!`, GitHub Actions, GHCR.

**Spec:** spike decisions in this conversation (2026-10-14). No separate design doc.

## Global Constraints

- Zero runtime frontend I/O: no download, no unzip, no Node, no extra files next to the binary.
- Do not add `rust-embed` / `include_dir`. `include_bytes!` generated by `build.rs`.
- Do not change `Cargo.toml` `version` (breaks `Semver::current()`). Suffix lives in `resources/RL_VERSION`.
- Do not insert the default `Application` that points at GitHub `webui.zip`.
- Windows ARM and FreeBSD ARM are out. linux armv7 musl binary in, no `linux/arm/v7` image.
- Features: `sqlite postgres mysql rocks s3 redis azure nats enterprise`.
- Registry: `ghcr.io/rezishon/stalwart`. Repo: `Rezishon/stalwart`.
- Targeted tests only. No full suite.

| `resources/RL_VERSION` | fork suffix, currently `rl1` |
| `resources/assets.lock` | pinned URLs + sha256 for webui zip and signup-relay rev |
| `scripts/fetch-assets.sh` | refresh lock targets into `resources/webui.zip` and `crates/deltachat/assets/` |
| `crates/common/build.rs` | unzip `resources/webui.zip` into `OUT_DIR`, emit `webui_embed.rs`; set `STALWART_VERSION` |

### Task 5: `assets.lock` + `fetch-assets.sh`

**Files:**
- Create: `resources/assets.lock`
- Create: `scripts/fetch-assets.sh` (posix, `set -euo pipefail`)
- Modify: `.gitignore` only if the script uses a cache dir

Lock format (key=value, no YAML):
```
webui_url=https://github.com/stalwartlabs/webui/releases/latest/download/webui.zip
webui_sha256=8bd645f75e19c4121d81be6d91a6ebe46a2958b0e7cae9a9b6d4530baef89c91
relay_repo=https://github.com/riselabs-group/signup-relay.git
relay_rev=9e37cd2567b89c148fc361e249bcbaa9d622da23
```

Script:
1. Download webui zip to temp, `sha256sum` must match, replace `resources/webui.zip`.
2. `git clone --depth 1` is wrong for a pinned rev — `git fetch --depth 1 origin <rev>` in a temp dir, `npm ci && npm run build` in `frontend/`, rsync `frontend/dist/` → `crates/deltachat/assets/` (delete extra hashed files).
3. `--update` (optional later): resolve current latest and rewrite hashes. **Not in v1.** Build never hits undownloaded `latest` without a sha check.

- [ ] **Step 1:** Write lock + script. Script must work offline if zip+assets already match.
- [ ] **Step 2:** Run `scripts/fetch-assets.sh` once with network if needed; if sha already matches, it is a no-op for webui.
- [ ] **Step 3:** Commit `chore(release): pin webui zip and signup-relay rev`
